# Synthetic data only

Every row in `synthetic_ivf_raw.csv` is generated by `src/generate_data.py` using NumPy random generator seed `20260618`. No real patients, clinic records, names, phone numbers, addresses, or hospital identifiers are used. IDs are fictional strings prefixed `SYN-`. The raw table is cycle-level: each row represents one treatment cycle; multiple cycles may share a synthetic patient ID. Embryo attributes are cycle-level summaries of a transfer candidate, not embryo-level observations. Do not treat this data as representative of any population, clinic, treatment, or clinical outcome.

`synthetic_ivf_cleaned.csv` is generated by `src/data_quality.py`. It retains missing outcomes where no transfer occurred or where an outcome is unknown. Unknown outcomes are not coded as negative. For ML, only transfer cycles with known clinical-pregnancy target are included.

The synthetic outcome generator uses an illustrative logistic probability formula with mild age, AMH, cycle grade, stage, endometrial-thickness, protocol and transfer-count terms. Biochemical pregnancy and live birth are separately simulated conditional on clinical pregnancy. These assumptions are pedagogical, unvalidated, not treatment recommendations, and not clinical probabilities. INR costs are fictional simulated amounts.

Regenerate reproducibly from repository root:

```bash
python -m src.generate_data --n-cycles 3000 --seed 20260618
```

Intentional raw quality examples include five duplicate rows, two malformed cycle-date strings, missing AMH/progesterone/endometrial-thickness/cost values, 34 unknown clinical outcomes among transfers, two out-of-range ages, two invalid BMIs, a cycle-count inconsistency, and non-standard category capitalization/spacing. The generator source documents each injection. Use data dictionary `synthetic_ivf_data_dictionary.csv` for all fields.
